JavaScript এ Array লেখার বিভিন্ন উপায়

১. Array Literal (সবচেয়ে সহজ ও জনপ্রিয় পদ্ধতি)

থার্ড ব্র্যাকেট [] ব্যবহার করে এরে তৈরি করা হয়।

const fruits = ['আম', 'কলা', 'লিচু'];

২. Array Constructor (new Array Keyword)

new Array() ব্যবহার করে এরে তৈরি করা যায়।

const colors = new Array('লাল', 'সবুজ', 'নীল');

৩. Array.of() Method

যেকোনো সংখ্যক ভ্যালু নিয়ে নতুন এরে তৈরি করে।

const numbers = Array.of(10, 20, 30, 40);

৪. Array.from() Method

কোনো স্ট্রিং বা ইটারেবল অবজেক্ট থেকে এরে তৈরি করে।

const chars = Array.from('JS-Tutorial');
